# Профили исходных ситуаций среды RBTE

**Рабочий продукт:** WP-45

**Статус:** черновик; тринадцать профилей исходных ситуаций подготовлены для проверки пилотом

**Формат:** профиль исходной ситуации, представленный через характеристики задачи (`TaskSignature`), и отдельное отношение его назначения проблемной ситуации и принимающему использованию (`TaskSignatureAssignmentRelation`) по FPF C.22

Каждый профиль описывает одну исходную ситуацию целиком и фиксирует только характеристики, необходимые указанному принимающему использованию. Профиль не равен классу задачи: внутри одной ситуации может находиться несколько задач, а один класс задачи может встречаться в нескольких ситуациях. Профиль не выбирает метод, не выдаёт вердикт о пригодности, не является планом работы и не доказывает достижение результата. Значение `unknown` сохранено только для значимой, но ещё не установленной характеристики. Поле результата (`ResultKind`) отсутствует во всех профилях.

## Общая форма

- **Редакция:** 2026-08-04; изменение смыслового поля создаёт следующую редакцию.
- **Идентичность:** содержание декларации, точный `EntityOfConcernRef` и действующая `ReferenceScheme`; название раздела и редакция служат только обозначениями.
- **Тип предмета (`SubjectKind`):** точная способность или объект работы, названные в `EntityOfConcernRef` конкретного профиля.
- **Тип значений (`RangedValueKind`):** типизированные характеристики задачи.
- **Правило протяжённости (`ExtentRule`):** профиль действует, пока не изменены проблемная формулировка, схема понятий, область утверждений или значения, на которые опирается принимающее использование.
- **Словарь (`Vocabulary`):** `TaskKind`, `SliceSet` и строки таблицы характеристик конкретного профиля.
- **Законы (`Laws`):** неизвестное не заменяется догадкой; метод и результат выбора не входят в профиль; сравнение использует только заявленные шкалы и полярности; изменение смыслового поля требует новой редакции.
- **Применимость (`Applicability`):** только указанная проблемная сторона, область и принимающее использование при актуальных основаниях значений.
- **Результаты вне профиля:** пригодность метода, выбор, план, выполненная работа, измерение и приёмка остаются у своих непосредственных владельцев.
