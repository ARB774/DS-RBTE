# PACK-adult-learning

DPF / IWE Pack предметной области «Проектирование обучения взрослых и программ ДПО».

Версия `0.1.0-draft` построена по локальным материалам из `for_dpf`. Pack описывает доменное знание: понятия, различения, роли, методы, рабочие продукты, типовые отказы и основания актуальности. Он не является готовой учебной программой и не задаёт расписание конкретного курса.

## Быстрый вход

1. [Манифест](00-pack-manifest.md) — границы, зрелость и индекс.
2. [Онтология](ontology.md) — единый словарь.
3. [Ключевые различения](01-domain-contract/01B-distinctions.md) — что нельзя смешивать.
4. [Карта домена](07-map/AL.MAP.001-domain-map.md) — связи ролей, методов и рабочих продуктов.
5. [Сводная версия DPF](DPF.md) — компактное чтение одним документом.

## Статус

Это пригодный для загрузки в IWE минимальный DPF, но не завершённый отраслевой стандарт. Основные ограничения зафиксированы в манифесте и SoTA-регистре: узкий локальный корпус, неодинаковая доказательная сила источников, отсутствие отдельной проверки действующего российского регулирования ДПО и независимой экспертной валидации.
