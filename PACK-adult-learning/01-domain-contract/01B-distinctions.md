## [AL.D.001] Обучение ≠ преподавание

**Определение:** обучение — изменение способности субъекта; преподавание — деятельность роли, создающей условия для такого изменения.

| Обучение | vs. | Преподавание |
|---|---|---|
| Происходит у обучающегося | | Выполняется преподавателем/фасилитатором |
| Проверяется изменением действия или понимания | | Проверяется качеством созданных условий и рабочих продуктов |

**Почему важно:** проведённое занятие не доказывает, что обучение состоялось.  
**Related:** AL.M.002, AL.M.007; AL.WP.005, AL.WP.008.  
**Revision criterion:** изменить при появлении более операционального доменного определения, сохраняющего различие процесса и роли.

## [AL.D.002] Андрагогический принцип ≠ универсальный закон

**Определение:** принципы андрагогики — сильные проектные предположения об особенностях взрослых, которые нужно проверять на конкретной аудитории.

| Проектное предположение | vs. | Универсальный закон |
|---|---|---|
| Задаёт вопрос для диагностики | | Предписывает одинаковое решение всем |
| Допускает различную готовность к самостоятельности | | Считает любого взрослого полностью автономным |

**Почему важно:** взрослые различаются опытом, мотивацией, культурой, возрастом и контекстом.  
**Related:** AL.M.001, AL.M.004.  
**Revision criterion:** пересмотр по данным, опровергающим контекстную применимость принципов.

## [AL.D.003] Образовательный запрос ≠ тема курса

**Определение:** запрос описывает значимый разрыв в способности действовать; тема обозначает область содержания.

| Запрос | vs. | Тема |
|---|---|---|
| «Научиться выбирать и обосновывать метод оценки программы» | | «Оценка обучения» |
| Содержит контекст, результат и ограничения | | Обозначает предмет разговора |

**Почему важно:** проектирование по теме ведёт к выгрузке контента вместо изменения деятельности.  
**Related:** AL.M.001; AL.WP.001, AL.WP.002.

## [AL.D.004] Результат обучения ≠ учебная активность

**Определение:** результат — демонстрируемая способность после обучения; активность — то, что участник делает во время обучения.

| Результат | vs. | Активность |
|---|---|---|
| Проверяемое действие и критерий | | Лекция, дискуссия, просмотр видео |
| Сохраняет смысл вне занятия | | Может завершиться без переноса |

**Почему важно:** высокая активность не гарантирует освоение.  
**Related:** AL.M.002, AL.M.007; AL.WP.002, AL.WP.005.

## [AL.D.005] Метод ≠ формат ≠ инструмент

**Определение:** метод преобразует входы в результат, формат задаёт организационную форму взаимодействия, инструмент облегчает выполнение.

| Method | Format | Tool |
|---|---|---|
| Проблемно-кейсовое обучение | Очная группа / онлайн-сессия | LMS / доска / симулятор |

**Почему важно:** покупка платформы или перевод в онлайн не создают метод.  
**Related:** AL.M.003; AL.FM.004.

## [AL.D.006] Обратная связь ≠ оценка

**Определение:** обратная связь помогает скорректировать следующее действие; оценка фиксирует суждение о соответствии критериям.

| Feedback | vs. | Assessment |
|---|---|---|
| Ориентирована на улучшение | | Ориентирована на решение/фиксацию |
| Может быть неоценочной | | Требует критерия и основания |

**Почему важно:** смешение превращает развивающий диалог в контроль или оставляет итог без доказательства.  
**Related:** AL.M.002, AL.M.007; AL.WP.005.

## [AL.D.007] Освоение ≠ удовлетворённость ≠ перенос

**Определение:** удовлетворённость описывает восприятие опыта, освоение — приобретённую способность, перенос — применение вне учебной ситуации.

| Satisfaction | Learning | Transfer |
|---|---|---|
| «Мне было полезно» | «Я могу выполнить по критериям» | «Я применяю на рабочем месте» |

**Почему важно:** положительная анкета не доказывает изменение поведения или результата организации.  
**Related:** AL.M.006, AL.M.007; AL.WP.008.

## [AL.D.008] Трансформация рамки ≠ эмоциональная встряска

**Определение:** трансформативное обучение предполагает критический пересмотр оснований и интеграцию новой рамки, а не просто сильную эмоцию.

| Transformative learning | vs. | Emotional impact |
|---|---|---|
| Диалог, рефлексия, проверка новой позиции | | Удивление, кризис или вдохновение без интеграции |

**Почему важно:** намеренное разрушение убеждений без поддержки создаёт риск и не доказывает обучение.  
**Related:** AL.M.002, AL.M.005; AL.FM.008.

## [AL.D.009] Персонализация ≠ бесконтрольный выбор

**Определение:** персонализация соотносит маршрут с запросом, готовностью и критериями результата; бесконтрольный выбор снимает общую рамку качества.

| Personalization | vs. | Unbounded choice |
|---|---|---|
| Вариативный путь к проверяемому результату | | Любой контент без обязательств |
| Поддержка соразмерна готовности | | Одинаковая автономия для всех |

**Почему важно:** свобода без структуры перегружает, особенно при низкой готовности к самонаправлению.  
**Related:** AL.M.004, AL.M.005; AL.WP.006.

## [AL.D.010] Эвристика 70–20–10 ≠ нормативная квота

**Определение:** 70–20–10 — ориентир, напоминающий о роли опыта и социального обучения, а не универсальная пропорция бюджета или времени.

| Heuristic | vs. | Quota |
|---|---|---|
| Помогает проверить баланс источников опыта | | Требует ровно заданных процентов |
| Настраивается по работе и риску | | Игнорирует контекст |

**Почему важно:** буквальная арифметика создаёт ложную точность и может вытеснить критерии результата.  
**Related:** AL.M.006; AL.FM.010.  
**SoTA:** `hypothesis` в части конкретных долей; ценность сохраняется как проектная эвристика.
