# Bounded Context: проектирование обучения взрослых и программ ДПО

## Domain name

**Проектирование обучения взрослых и программ дополнительного профессионального образования**  
English: **Adult Learning and Continuing Professional Education Design**

## Object of description

| Object is | Object is not |
|---|---|
| Воспроизводимая практика преобразования запроса взрослого в учебный опыт и наблюдаемый результат | Конкретный слушатель с полной биографией |
| Система ролей, методов, рабочих продуктов и критериев качества | Набор лекций или контентный каталог |
| Связка обучения, профессионального контекста и переноса в действие | Только администрирование ДПО |
| Доменное знание для проектировщиков и организаторов | План одной программы |

## Scope

| Element | Description | Example |
|---|---|---|
| Взрослый обучающийся | Совершеннолетний субъект с опытом, целями, ограничениями и ответственностью за выбор | Специалист, меняющий профессию |
| Образовательный запрос | Разрыв между текущей и желаемой способностью действовать, помещённый в контекст | «Научиться проводить аудит процесса по заданным критериям» |
| Учебный опыт | Организованная связка действия, обратной связи, рефлексии и концептуализации | Кейс с разбором решения |
| Сопровождение | Поддержка самонавигации, самоорганизации, самоопределения и рефлексии | Тьюториал до и после стажировки |
| Перенос | Применение освоенного в реальной деятельности | Рабочее задание с наблюдением руководителя |
| Доказательность | Связь утверждаемого эффекта с наблюдаемыми индикаторами и данными | Рубрика продукта и проверка поведения на рабочем месте |
| Экосистема ДПО | Взаимодействие обучающегося, провайдера, работодателя и других партнёров | Сетевая программа со стажировкой |

## Non-goals

| Excluded | Reason | Belongs to |
|---|---|---|
| Расписание, бюджет и состав конкретной программы | Это локальная реализация | DS проекта программы |
| Юридическое заключение о соответствии требованиям | Нужна отдельная актуальная экспертиза | Правовой/регуляторный Pack или DS |
| Сравнение LMS и моделей ИИ | Инструменты быстро меняются | Технологический Pack/DS |
| Лечение тревожных и кризисных состояний | Выходит за компетенцию образовательной практики | Клиническая/психологическая помощь |

## Truth criteria

| Criterion | Test |
|---|---|
| Наблюдаемый результат | Можно показать действие, продукт или изменение поведения |
| Проверяемый рабочий продукт | Есть форма, владелец и критерии качества |
| Различение | Понятно, с чем сущность часто путают и почему это важно |
| Трассируемость | Утверждение связано с источником и статусом доверия |
| Пересматриваемость | У метода или гипотезы указан критерий пересмотра |

Запрещены утверждения без наблюдаемого смысла, методы без выходов, технологические рекомендации без контекста и сильные причинные выводы из обзорных статей.

## Downstream note

Pack описывает, **что существует и по каким критериям различается**. Конкретная программа определяет, **как именно эти сущности применяются** для своей аудитории, темы, бюджета, формата и срока.
