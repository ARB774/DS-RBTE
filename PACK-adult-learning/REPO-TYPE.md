# Repository type

```yaml
type: Pack
pack_id: AL
pack_name: Adult Learning and Continuing Professional Education
upstream:
  - FPF
  - SPF
version: 0.1.0
status: draft
```

DPF и Pack используются как эквивалентные названия наполненного доменного уровня. Здесь хранится знание предметной области; проектные планы, реализации конкретных программ и организационные регламенты относятся к downstream-системам.
