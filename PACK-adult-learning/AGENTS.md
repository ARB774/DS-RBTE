# Инструкции для Codex

- Считать этот каталог source-of-truth по доменному знанию об обучении взрослых в пределах версии `0.1.0`.
- Перед ответом по теме читать `00-pack-manifest.md`, затем выбирать сущности через `07-map/AL.MAP.001-domain-map.md`.
- Не превращать описание метода в пошаговый план конкретного курса без отдельного downstream-запроса.
- Не смешивать метод, формат, инструмент, рабочий продукт и показатель.
- Любое новое утверждение помечать источником и статусом `current`, `hypothesis` или `deprecated-interpretation`.
- Если источник обзорный или коммерческий, не повышать его до доказательного без независимой проверки.
- При изменении сущностей обновлять манифест, карту и журнал изменений.
