# Показ схемы ТОС в окне браузера

Предъявляй участнику одну актуальную Тучу или ДТР в постоянно открытом окне браузера.
Основной наставник строит и проверяет логику; этот навык только обновляет рисунок.

## Выполнение

1. Получи абсолютный путь к актуальному PNG и номер версии схемы. Если исходник
   существует только как SVG, сначала отрендери PNG размером не менее
   `1600 × 960 px`. Не меняй содержание блоков.
2. Через `functions.exec` вызови MCP-инструмент `show_cloud` сервера
   `toc-cloud-display`:

```javascript
const result = await tools.mcp__toc_cloud_display__show_cloud({
  image_path: absolutePngPath,
  title: cloudTitle,
  version: cloudVersion,
});
const browserViewPath = result.structuredContent?.browserViewPath;
if (!browserViewPath) throw new Error("Модуль не вернул путь к окну схемы ТОС");
text(`Окно схемы ТОС обновлено: ${browserViewPath}`);
```

3. Не передавай рисунок через `image(...)`, `generatedImage(...)` или
   `view_image`: Codex Desktop может скрыть эти результаты. Вызов `show_cloud`
   сам публикует PNG для уже открытого окна браузера.
4. При первом показе в сессии убедись, что окно `cloud-view.html` открыто. Если
   участник явно разрешил открыть его, запусти возвращённый `browserViewPath` в
   браузере как видимое интерактивное окно. Не открывай новое окно при каждом
   обновлении.
5. Первый раз спроси, видно ли окно и читается ли текст. Для Тучи проверь пять
   блоков и стрелки; для ДТР — всю текущую причинную карту. После подтверждения
   обновляй то же окно после каждого изменения схемы без повторной проверки.
6. Не говори «показано» или «окно обновлено» до успешного ответа `show_cloud` с
   `browserViewPath`. Для содержательного изменения передавай в `version` его
   краткое обозначение, например `У7 → НЖЯ 1`, чтобы публикацию нельзя было
   спутать с предыдущей версией.

## Остановка

Если `show_cloud` завершился ошибкой, окно браузера не обновилось или участник
сообщил, что изменения не видит, считай показ несостоявшимся и не продолжай
содержательную работу со схемой. Сообщи, что именно не удалось: рендеринг PNG,
публикация PNG или обновление окна. Не возвращайся к встроенному показу в диалоге.
