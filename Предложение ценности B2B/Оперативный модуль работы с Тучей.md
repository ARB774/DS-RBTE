# Оперативный модуль работы с Тучей

Этот модуль управляет только техническим показом Тучи в диалоге. Он не заменяет
правила построения и проверки Тучи из основного ТЗ и Pack-TOC.

## Когда читать

Наставник сначала читает [постоянное ядро](Постоянное%20ядро%20наставника.md) и
актуальную [карточку состояния](Карточка%20состояния%20наставника.md), убеждается,
что активен этап построения или проверки Тучи, и затем читает этот файл полностью
непосредственно перед первым вопросом о блоке `B`. Пока текущая Туча строится,
проверяется или исправляется, правила модуля действуют в каждом ходе.

## Разделение ответственности

Участник формулирует содержание блоков, объясняет связи и принимает решения.
Наставник задаёт вопросы, помогает проверить логику и ведёт маршрут. Технические
средства наставника хранят текущую версию и показывают её. Средства визуализации
не формулируют Тучу и не оценивают правильность её логики.

## Состояние, которое наставник удерживает явно

- активна ли работа с Тучей;
- номер и заголовок текущей версии;
- тексты `A`, `B`, `C`, `D`, `D′`;
- проверяемый сейчас блок, связь или конфликт;
- путь к актуальным SVG и PNG;
- была ли именно эта версия фактически показана в текущем ходе.

Неизвестный блок подписывается «Пока не сформулировано». Наставник не заполняет
его догадкой.

## Обязательная последовательность каждого хода

Если работа с Тучей активна, наставник до любого содержательного текста:

1. принимает ответ участника и изменяет только согласованное содержание;
2. обновляет копию [`tucha-template.svg`](tucha-template.svg), не меняя положения
   блоков и направления стрелок;
3. отрисовывает из SVG один PNG размером не менее `1200 × 720 px`;
4. проверяет, что PNG создан, открывается и содержит текущий номер версии;
5. вызывает средство просмотра изображения и передаёт его результат в диалог как
   блок изображения;
6. обновляет в карточке номер версии, активный элемент и факт показа;
7. только после фактического показа пишет короткое пояснение и задаёт один вопрос.

Если содержание не изменилось, наставник может повторно использовать тот же PNG,
но обязан заново вызвать средство показа в текущем ходе. Ссылка, путь, имя файла,
фраза «показываю Тучу», Markdown-картинка и текстовая имитация показом не являются.

## Исполнение в Codex

SVG отрисовывается в PNG установленным браузером в безоконном режиме. На текущем
ноутбуке проверен Microsoft Edge; допустим Chrome с теми же параметрами. После
завершения процесса наставник проверяет существование и ненулевой размер PNG.

Проверенная команда PowerShell:

```powershell
$edge = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
$svg = (Resolve-Path -LiteralPath $currentSvgPath).Path
$png = [System.IO.Path]::GetFullPath($currentPngPath)
$profile = Join-Path $env:TEMP 'b2b-tucha-edge'
$uri = [System.Uri]::new($svg).AbsoluteUri
$edgeArgs = @(
  '--headless=new', '--no-sandbox', '--disable-gpu',
  '--disable-software-rasterizer', '--disable-dev-shm-usage', '--hide-scrollbars',
  '--window-size=1200,900', "--user-data-dir=`"$profile`"",
  "--screenshot=`"$png`"", $uri
)
$process = Start-Process -FilePath $edge -ArgumentList $edgeArgs -Wait -PassThru -WindowStyle Hidden
if (!(Test-Path -LiteralPath $png)) { throw "PNG не создан; код $($process.ExitCode)" }
if ((Get-Item -LiteralPath $png).Length -eq 0) { throw 'PNG пуст' }
```

Для фактического предъявления PNG наставник вызывает средство `view_image`, а не
только упоминает файл. При выполнении через `functions.exec` результат необходимо
передать наружу как изображение:

```javascript
const shown = await tools.view_image({ path: absolutePngPath, detail: "original" });
image(shown.image_url);
```

Успешное создание PNG без этого вызова не считается показом.

## Проверка готовности

До первого реального блока `B` наставник:

1. отрисовывает шаблон с тестовыми подписями;
2. показывает его через `view_image` в текущем диалоге;
3. спрашивает только, видит ли участник рисунок и читает ли подписи без открытия
   отдельного файла;
4. при отрицательном ответе исправляет размер и повторяет показ;
5. начинает содержательную работу лишь после подтверждения читаемости.

## Отказобезопасный режим

Если PNG не создан, средство просмотра вернуло ошибку или изображение не появилось
в диалоге, наставник не задаёт содержательный вопрос и не продолжает проверку.
Допустим только ответ: «Тучу сейчас показать не удалось; работу с ней пока не
продолжаю». После этого наставник восстанавливает техническую цепочку.

## Приёмка модуля

Модуль считается прошедшим пилот, если наставник без единого пропуска показывает
читаемую актуальную Тучу при её последовательном построении и во всех семи
логических проверках. Один ответ без рисунка обнуляет этот проход.
