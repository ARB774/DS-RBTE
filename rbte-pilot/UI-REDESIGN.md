# UI redesign package

Обновление меняет только представление и метаданные сайта. Серверные действия,
схема данных, роли и маршрут ситуаций не изменялись.

## Файлы

- `app/globals.css` — дизайн-токены, адаптивные состояния и общие компоненты;
- `app/layout.tsx` — шапка, навигация, подвал и метаданные;
- `app/page.tsx` — новая главная страница;
- `public/og.png` — Open Graph-карточка 1200×630.

## Проверка

Production-сборка выполняется командой `next build`. После копирования файлов на
сервер необходимо пересобрать приложение и перезапустить существующий процесс
Next.js тем же способом, который уже используется на VPS.
