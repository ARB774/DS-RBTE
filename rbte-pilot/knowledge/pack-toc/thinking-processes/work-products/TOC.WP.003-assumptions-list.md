# Список исходных предположений (ИП)

**Вход:** построенная туча (`TOC.WP.004`).
**Метод:** выявление и опознание ИП за каждой стрелкой (`TOC.M.004`, Этап 2 работы с тучей).
**Выход:** список атомарных ИП — каждое утверждение односложно, связывает оба элемента стрелки, записано без префикса «потому что», проходит проверку «X + ИП → Y».

Список ИП — вход для Этапа 3 (оспаривание предположений и формулировка инъекции).
