# Материалы наставника предложения ценности

`lib/value-proposition-evidence.json` содержит зафиксированные выдержки DS-RBTE
и полные документы Pack-TOC, выбранные для этапа. Запись указывает репозиторий,
коммит, исходный путь, строки и SHA-256 полного исходного документа после
нормализации CRLF в LF. Документы DS-RBTE взяты из редакции 047806b,
Pack-TOC — из существующего manifest `pack-toc-sources.json`.

При каждом ходе наставник получает ядро, восстановление контекста и материал
текущего этапа. На этапах Тучи, предположений и решения добавляется предметный
источник Pack-TOC. Это локальная поставка зафиксированных источников, а не
онлайн-поиск или MCP. JSON импортируется в серверный модуль и включается в
standalone-сборку: дополнительных runtime-файлов и GitHub-токена не требуется.

Критерий ответа должен называть источник. Это указание модели, а не проверка
семантической корректности ссылки. Изменения источников требуют обновления
снимка и проверки владельцем предметного знания. Тесты сверяют снимок
с оригиналами, выбор источников для этапов и фактическое тело запроса модели.

Правило S0 учитывает допустимый исследовательский режим из ТЗ: экспертная
гипотеза и реалистичный путь проверки позволяют продолжить работу. Исправление
не меняет БД, историю проекта или критерии перехода программно; решение
о готовности по-прежнему формирует модель. История по-прежнему ограничена
последними 36 записями; постоянная память согласованных пунктов требует
отдельного изменения модели данных.
